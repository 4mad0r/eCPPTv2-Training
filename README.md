# eCPPTv2 Preparation – Pentest Writeups

This repository documents my preparation journey for the **eCPPTv2** certification by INE Security, collecting structured penetration testing write-ups of the labs and machines I complete along the way.

> 🇬🇧 Most write-ups will be in Spanish, with some notes in English.  
> 🇪🇸 La mayoría de los writeups estarán en español, con algunas notas en inglés.

---

## 📁 Repository Structure / Estructura del repositorio

Planned structure (subject to change):

- `htb/` – Hack The Box machines & challenges  
- `pg/` – Proving Grounds / Offensive Security labs  
- `ine-labs/` – INE labs related to eCPPTv2  
- `misc/` – Other CTFs, vulnerable machines or practice scenarios  
- `tools/` – Helper scripts, one-liners, cheatsheets

Cada carpeta incluirá un `README.md` propio o un archivo por máquina con su writeup.

---

## 🧠 Writeup Format / Formato de los writeups

Cada writeup intentará seguir una estructura similar:

1. **Overview / Resumen**
2. **Reconnaissance & Enumeration / Recon y enumeración**
3. **Vulnerability Analysis / Análisis de vulnerabilidades**
4. **Exploitation / Explotación**
5. **Post-Exploitation / Post-explotación**
6. **Privilege Escalation / Escalada de privilegios (si aplica)**
7. **Remediation & Lessons Learned / Medidas y lecciones aprendidas**

---

## 🛠️ Tools & Stack / Herramientas

A non-exhaustive list of tools and techniques used along the way:

- Network scanning & enumeration (e.g. `nmap`, `masscan`)
- Web application testing (e.g. `Burp Suite`, browser extensions)
- Exploitation frameworks and custom scripts
- Linux & Windows privilege escalation techniques
- Post-exploitation, persistence and lateral movement basics

El objetivo es documentar no solo los comandos, sino también **el razonamiento detrás de cada paso**.
